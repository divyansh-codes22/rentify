# 🛒 Rentify – Electronic Rental Platform

Rentify is a modern web-based platform that allows users to **browse and rent electronic devices and books online**. The project focuses on providing a **user-friendly interface, smooth navigation, and responsive design**.

---

## 🚀 Features

- 🔍 Browse electronic devices and books
- 🛍️ Rent items easily through a simple interface
- 📱 Fully responsive design (mobile + desktop)
- ⚡ Fast and smooth user experience
- 🎯 Clean and intuitive UI

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- HTML5
- CSS3
- JavaScript

**(Optional Backend - if added):**
